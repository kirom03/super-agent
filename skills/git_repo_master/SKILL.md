# Git & Codebase Master Skill

When managing project codebases:
1. Use `execute_terminal_command` with `git status`, `git log -n 5`, `git diff` to understand repo changes.
2. Ensure commit messages follow Conventional Commits standard (`feat:`, `fix:`, `docs:`, `refactor:`).
3. Do not run destructive git commands (`git reset --hard`, `git clean -f`) without user approval.
